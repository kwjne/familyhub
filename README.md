# 🏛 ВТБ Семья (Family Hub)

> Инновационный сервис семейного банкинга и геймифицированной финансовой культуры для экосистемы **Банка ВТБ**.  
> Разработано в рамках всероссийского ИТ-соревнования **«Академия Финтеха»** (Трек: *«Финтех без границ: банк будущего для бизнеса и клиентов»*).

## 🎯 Проблематика и контекст
По данным Аналитического центра НАФИ, **более 82% российских школьников** регулярно получают карманные деньги, но **менее 20%** ведут их осознанный учет. До 80% родителей переводят средства ситуативно, без связи с личными целями ребенка и полезными привычками.

**ВТБ Family Hub** решает эту проблему через принцип **«Обучение через действие»**:
- Дети зарабатывают карманные деньги, выполняя развивающие задания (спорт, учеба, быт).
- Семья объединяет накопления на общие долгосрочные цели в «Семейной копилке».
- Банк получает приток пассивов (CASA) и долгосрочную лояльность аудитории задолго до получения первого паспорта.

## 🏗 Архитектура решения (Headless / API-First)

Проект спроектирован по принципу независимого сервисного ядра:
1. **Core REST API:** Бизнес-логика жизненного цикла квестов, банковских счетов, финансового аудита и семейных целей.
2. **Adaptive Webview Client:** Интерфейс в дизайн-системе ВТБ Онлайн для встраивания как нативный Microfrontend / Mini-App.
3. **Telegram Push-Bot:** Легковесный клиент для родителей — мгновенные интерактивные уведомления и подтверждение выплат в 1 клик.

### Стек технологий:
- **Backend:** Java 21, Spring Boot 4.1.1, Spring Data JPA, Hibernate ORM
- **Database:** PostgreSQL (промышленная), H2 In-Memory (для MVP)
- **Messaging & Notifications:** Spring Application Events, Telegram Bot API (Long Polling)
- **Frontend / WebView:** HTML5, Tailwind CSS, JavaScript (автосинхронизация состояния)
- **DevOps:** Docker, Docker Compose, GitHub Actions CI

## 🔒 Безопасность и финтех-механики
- **State Machine валидация:** Жесткий контроль статусов (`CREATED` → `SUBMITTED` → `APPROVED`/`REJECTED`). Выплата наград возможна исключительно после сдачи задания ребенком.
- **Audit & Transaction Ledger:** Каждое начисление и пополнение копилки фиксируется в журнале финансовых транзакций с типами операций.
- **Идемпотентность и защита от повторных списаний:** Исключены сценарии двойных выплат при рассинхронизации клиентских интерфейсов.
- **Интеграция с СБП (симуляция):** Генерация динамических QR-кодов для мгновенного пополнения детской карты ВТБ Junior.

## 🚀 Быстрый запуск

### 1. Переменные окружения
Создайте файл `.env` или передайте параметры в `application.properties`:
```properties
TELEGRAM_BOT_USERNAME=vtb_family_hub_demo_bot
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```
### 2. Запуск через Docker Compose

    docker compose up -d --build

Сервис будет доступен:
- Веб-интерфейс: `http://localhost:8080`
- Swagger UI (OpenAPI документация): `http://localhost:8080/swagger-ui.html`

### 3. Локальный запуск из исходников

    mvn clean package -DskipTests
    java -jar target/familyhub-0.0.1-SNAPSHOT.jar
